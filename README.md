# Описание

    1.Выпускной проект "Планировщик задач"
Данный проект реализует функциональность планировщика задач.
Планировщик хранит задачи; каждая из них содержит дату дедлайна и заголовок с комментарием, pадачи повторяются по заданному правилу (ежегодно или через некторое колличество дней)
1. создан веб сервер
2. спроектирована и созадана БД (sqlite)
3. написана функция определющая правило повторения задач
4. Реализованы API обработчики на добавление/редактирование/удаление/получение задачи
    2.Задание повышенной трудности не выполнялись, если Ревью будет успешным и со сдачей проекта не возникнут трудностей, задачи со * будут реализваны 
    3.Для запуска кода локально необходимо:
1. установить go lang - https://go.dev/doc/install
2. в командной строке/терминале перейти в корневую папку проекта, ввести команду "go run main.go"
3. для проверки работоспособности необходимо перейти в браузере по ссылке http://localhost:7540/
    4.Параметры в test/settings.go:
    package tests
    var Port = 7540
    var DBFile = "../scheduler.db"
    var FullNextDate = false
    var Search = false
    var Token = ``
Тесты запускаются из корневой папки проекта командой: go test ./tests
